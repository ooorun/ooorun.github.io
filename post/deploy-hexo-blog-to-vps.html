快速把 Hexo 博客部署到 VPS 教程指南

2026-10-16 #Debian#Hexo

虽然 Hexo 的博客可以部署到 GitHub 、Cloudflare Pages 等免费服务上，但是如果你有一台访问超快的 VPS，也可以选择直接部署到自己的 VPS 上。

将 Hexo 博客部署到自己的 VPS 上，核心原理是在服务器上创建一个Git 裸仓库（Bare Repository），并通过 Git 的 post-receive 钩子（Hook），在每次本地执行 hexo d 推送静态文件时，自动将最新代码检出（Checkout）到 Web 服务器的网站根目录下。

以下是完整的手动配置流程，文末附带一键自动化部署脚本。

一、 手动配置步骤

假设你的服务器系统为 Debian / Ubuntu，目标是将博客源码推送到 /var/repo/hexo.git，并将生成的静态网页自动同步到 /var/www/hexo。

1. 安装 Git 并创建专用用户

在 VPS 上执行，出于安全考虑，限制 git 用户通过 SSH 登录交互式 Shell。

首先确保服务器已安装 Git，然后创建一个名为 git 的系统用户，并将其默认 Shell 修改为 git-shell（仅允许执行 Git 推送/拉取操作，禁止常规命令行登录）。

脚本亮点

  • 幂等性设计：可重复执行，已存在的用户、公钥或目录会自动跳过，方便随时新增第二个、第三个静态站点仓库。
