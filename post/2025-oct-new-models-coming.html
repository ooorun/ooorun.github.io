AI 大模型集中发布：DeepSeek 3.2、Claude Sonnet 4.5、OpenAI Sora 2、GLM-4.6 亮点速览

2025-10-01 #AI#大模型#DeepSeek#Claude#Claude Code#OpenAI#智谱AI

9月29日，AI 领域迎来了一波重磅更新。DeepSeek、Anthropic、OpenAI 和智谱 AI 四家公司不约而同地发布了各自的最新模型，为开发者和用户带来了更强大的 AI 能力。

DeepSeek-V3.2：开源大模型再突破，成本下降超 50%

9月29日，DeepSeek 正式在 Hugging Face 平台发布并开源了 DeepSeek-V3.2-Exp 模型。

模型地址：https://huggingface.co/deepseek-ai/DeepSeek-V3.2-Exp

API 价格大幅下调超 50%

新模型主要特点是服务成本的显著降低，DeepSeek 随即下调 API 调用费用：官方 API 价格下调超过 50%，新价格已即刻生效。这一举措将大幅降低开发者的使用成本。

Anthropic Claude Sonnet 4.5：自主编程能力跃升

9月29日，Anthropic 发布了全新的 Claude Sonnet 4.5 模型。

官方介绍：https://www.anthropic.com/news/claude-sonnet-4-5

核心亮点

  • 指令遵循能力显著提升：模型对复杂指令的理解和执行更加精准
  • 长时间自主编程：可连续自主编程长达 30 小时，相比 Claude Opus 4 的 7 小时提升了 4 倍以上
  • 立即可用：已在 Claude Code 中上线，开发者可直接使用

OpenAI Sora 2：视频生成的 ChatGPT 时刻

9月29日，OpenAI 推出了其迄今最先进的视频生成模型 Sora 2.0，并同步上线独立 iOS 应用（目前采用邀请机制）。

主要特性

  • 物理真实感大幅提升：生成视频的物理表现更加逼真
  • 音视频同步优化：声音与画面的匹配度显著提高
  • 多镜头叙事能力：支持更复杂的故事叙述方式
  • 社交互动功能：用户可生成、浏览和分享 AI 视频，甚至以虚拟形象”客串”他人作品

OpenAI 将此次更新称为”视频生成的 ChatGPT 时刻”，意味着视频生成技术正在迎来质的飞跃。

官方介绍与 Demo 预览：https://openai.com/index/sora-2/
可以在官方 Discord 获取其他用户分享的邀请码（加入社群需要连接 OpenAI 账户）： https://discord.gg/openai

Sora by OpenAI (iOS APP) 介绍

下载地址：https://apps.apple.com/us/app/sora-by-openai/id6744034028

目前支持美国、加拿大、日本地区的 Apple ID 下载。

获取方式

OpenAI 采用邀请码裂变机制推广 Sora APP：每个账户加入后可生成一个邀请码，每个邀请码可以使用 4 次。

使用流程：下载 APP → 使用 OpenAI 账户登录 → 输入邀请码即可开始使用。

产品定位

Sora by OpenAI 是一款短视频社交平台，定位类似 TikTok，核心区别在于所有内容均由 AI 生成。用户可以创作、浏览和分享 AI 视频，打造全新的社交体验。

核心功能

  • 文本生成视频：通过一句话描述即可生成 10 秒视频
  • 草稿管理：生成的视频会自动保存为草稿，用户可选择下载到本地或公开发布到平台
  • Cameo 功能：扫描 3D 人脸并克隆音色，创建个人数字分身，供 AI 在视频生成时使用
  • 权限控制：Cameo 支持灵活的权限设置，保护用户隐私
  • 社交互动：生成视频时，通过 @ 可引用其他用户的 Cameo。例如 @sama 可让 OpenAI CEO 直接出现在你的视频中，实现创意联动

智谱 GLM-4.6：对齐 Claude Sonnet 4

智谱 AI 更新了旗舰模型 GLM-4.6，在多个维度实现了显著提升。

核心亮点

代码能力大幅提升

  • 较 GLM-4.5 提升了 27%
  • 在公开基准与真实编程任务中，代码能力对齐 Claude Sonnet 4

上下文窗口扩展

  • 从 128K 提升到 200K
  • 能更好地处理复杂代码项目和需要长程记忆的智能体任务

推理能力增强

  • 支持在推理过程中调用工具
  • 多步骤推理更加稳定可靠

写作与交互优化

  • 搜索能力、写作能力增强
  • 写作风格和可读性更贴近人类偏好
  • 在角色扮演等场景下表现更自然

Benchmark 对比

官方文档：https://docs.bigmodel.cn/cn/guide/models/text/glm-4.6
在线体验：https://z.ai

这次四家公司的集中发布，展现了 AI 大模型领域的激烈竞争与快速进步。从降价到性能提升，从代码生成到视频创作，AI 技术正在加速渗透到各个应用场景中。
