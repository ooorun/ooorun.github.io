  1. 配置两个 shard 的端口

Master：

mkdir -p ~/.klei/DoNotStarveTogether/Cluster_1/Master
nano ~/.klei/DoNotStarveTogether/Cluster_1/Master/server.ini

填：

[NETWORK]
server_port = 11000

[SHARD]
is_master = true

[STEAM]
authentication_port = 8768
master_server_port = 27018

LinuxGSM 官方示例也是 Master 使用：

server_port = 11000
authentication = 8768
master_server = 27018

洞穴：

mkdir -p ~/.klei/DoNotStarveTogether/Cluster_1/Caves
nano ~/.klei/DoNotStarveTogether/Cluster_1/Caves/server.ini

填：

[NETWORK]
server_port = 11001

[SHARD]
is_master = false
name = Caves

[STEAM]
authentication_port = 8769
master_server_port = 27019

LinuxGSM 官方示例给 Caves 使用不同的 11001 / 8769 / 27019，避免两个实例端口冲突。

  1. 检查洞穴世界配置

如果前面在安装前正确设置：

cave=”true”

LinuxGSM 应该已经自动生成：

~/.klei/DoNotStarveTogether/Cluster_1/Caves/worldgenoverride.lua

可以检查：

cat ~/.klei/DoNotStarveTogether/Cluster_1/Caves/worldgenoverride.lua

官方当前生成的配置类似：

return {
override_enabled = true,
preset = “DST_CAVE”,
}

LinuxGSM 文档明确说明，这个文件就是让 Caves 实例生成真正洞穴而非第二张地表地图的关键。

  1. 启动服务器

启动地面：

./dstserver-1 start

启动洞穴：

./dstserver-2 start

启动顺序其实无所谓，因为洞穴 shard 连不到 Master 时会自动重试。

查看状态：

./dstserver-1 details
./dstserver-2 details

LinuxGSM 的 details 会显示端口、配置路径、运行状态等信息。

  1. 看实时控制台

地面：

./dstserver-1 console

洞穴：

./dstserver-2 console

退出控制台：

Ctrl+B
然后按 D

不要按 Ctrl+C，因为可能直接终止服务器进程。LinuxGSM 官方文档也特别提醒了这一点。

  1. 常用管理命令

以后基本就是这些：

./dstserver-1 start
./dstserver-1 stop
./dstserver-1 restart
./dstserver-1 console
./dstserver-1 details

洞穴同理：

./dstserver-2 start
./dstserver-2 stop
./dstserver-2 restart
./dstserver-2 console
./dstserver-2 details

升级 DST：

./dstserver-1 update

强制 SteamCMD 更新：

./dstserver-1 force-update

验证服务器文件：

./dstserver-1 validate

备份：

./dstserver-1 backup

这些都是 LinuxGSM 自带的标准管理功能。

  1. 开放防火墙

如果启用了 UFW：

sudo ufw allow 11000/udp
sudo ufw allow 11001/udp

如果是阿里云、腾讯云、AWS、Oracle 等 VPS，还要在云服务器安全组里开放 UDP：

11000
11001

一般：

11000 → Master
11001 → Caves
15. 自动监控崩服

LinuxGSM 有 monitor 功能，可以检测服务器挂掉并重启。官方建议通过 cron 周期执行。

编辑：

crontab -e

例如：

*/5 * * * * /home/dstserver/dstserver-1 monitor > /dev/null 2>&1
*/5 * * * * /home/dstserver/dstserver-2 monitor > /dev/null 2>&1

这样每 5 分钟检查一次。

还可以自动检查更新：

*/30 * * * * /home/dstserver/dstserver-1 update > /dev/null 2>&1

LinuxGSM 官方 DST 页面本身也推荐使用 cron 执行 monitor 和 update。
